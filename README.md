# Java Servlet Experiment

## Aim
To develop a Java Servlet program and understand how servlets handle client requests and generate dynamic responses using a web server.

## Description
Java Servlet is a server-side Java technology used to handle HTTP requests and generate dynamic web content. In this experiment, a servlet is deployed on Apache Tomcat and accessed through a web browser.

## Technologies Used
- Java
- Java Servlet API
- Apache Tomcat 11
- HTML
- Visual Studio Code

## Requirements
- Java Development Kit (JDK)
- Apache Tomcat
- Visual Studio Code
- Java Servlet API compatible with the installed Tomcat version

## How to Run
1. Open the project in Visual Studio Code.
2. Write the servlet code and configure the web application.
3. Compile the servlet using the appropriate Servlet API library.
4. Deploy the web application to Apache Tomcat.
5. Start the Tomcat server.
6. Open a browser and access the application's configured URL.

## Expected Output
The servlet processes the client's request and returns a response that can be displayed in the web browser.

## Learning Outcomes
- Understanding Java Servlet technology.
- Learning request and response handling.
- Understanding servlet deployment on Apache Tomcat.
- Learning the basics of dynamic web applications.
